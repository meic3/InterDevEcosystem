In this project I wanted to make a ocean. I think I did pretty well in this project, because I made different creatures that moves and grows differently. I am perosnally proud of the octopus and the fishing rod. I think I really like the fishing rod because it spawns as there are more fish and it can catch the fish. And I like the octopus because the fish runs away when it gets close to the octopus, and the clown fish detects the octopus and runs away. And it splashes black ink to the screen. I learnt how to use coroutines and I also got a lot more used to using timers. I also learnt how to use particle systems, which I thought gave a pretty cool effect.
